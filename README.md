# SuperStore Project

Portfolio project for a commercial analysis of the SuperStore dataset using Excel and Power BI.

## Overview

This project analyzes sales, profitability, customers, products, and delivery time for a retail dataset from the United States.

## Main insights

- Discount levels above 50% generate a margin of -119.2%.
- The top 20% of customers generate 73.98% of sales.
- Q4 represents 38.22% of annual sales.
- Technology and Office Supplies lead profitability, while Furniture has the lowest margin.
